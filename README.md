# 3D Machine Learning Visualization Suite — Enterprise Advanced

An end-to-end, reproducible machine-learning notebook: classification, 3D/interactive visualization, model comparison, tuning, explainability, calibration, conformal prediction, drift monitoring, time-series backtesting and more.

> Demonstration / educational workflow built on the scikit-learn Breast Cancer Wisconsin dataset (bundled locally, no download). **Not a clinical diagnostic tool.**

## Highlights
- 6 model families compared (Logistic Regression, Random Forest, Extra Trees, Hist Gradient Boosting, MLP, optional XGBoost)
- 2D / 3D PCA projections, Plotly interactive 3D (optional)
- Explainability: feature importance, permutation importance, SHAP (optional), PDP/ICE
- Reliability: calibration, threshold optimization, conformal prediction, bootstrap CIs
- Production-style: data contracts, drift monitoring (PSI + KS), model card, inference bundle
- Optional TensorFlow/Keras network and CNN computer-vision example

## Quick start
```bash
pip install numpy pandas matplotlib seaborn scikit-learn scipy
pip install plotly xgboost shap tensorflow   # optional
jupyter notebook 3D_ML_Visualization_Suite_Enterprise_Advanced_Upgrade.ipynb
```
Run all cells top to bottom. Optional packages are auto-detected and skipped if missing.
